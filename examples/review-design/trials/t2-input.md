# 出荷指示機能 設計書

## 1. 概要

受注した商品の出荷を、倉庫に指示する。出荷担当が出荷指示書を印刷して使う。

## 2. 画面

### 2.1 入力

出荷指示画面で、受注番号を入力し、検索ボタンを押す。必要に応じて出荷予定日を変更できる。

### 2.1 確認

受注の明細を表示し、確定ボタンで出荷指示を作る。

## 4. 処理

1. 受注番号で受注を検索する。
2. 明細ごとに在庫を引き当てる。在庫が十分にない明細は、なるべく分けて出荷する。
3. 出荷指示を作り、状態を「指示済み」にする。
4. 配送業者のシステムに出荷の予定を送る。

## 5. 帳票

出荷指示書を印刷する。

## 6. 取消

出荷指示は取り消せる。
