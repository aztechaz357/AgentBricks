# 入力と出力の例

例を 1 組ずつ、同じ番号で並べる。架空の設計書。

- `01-input.md` (入荷登録機能のレビュー前) と `01-output.md` (指摘を受けて直した後)
- `02-input.md` (在庫不足通知機能のレビュー前) と `02-output.md` (指摘を受けて直した後)

指摘の一覧の実物 (`01-review.md`) はない。前と後の違いが、指摘で直したところ。

## 試した場面

直したあとに、同じ場面で試し直す。

- 例の入力: 01-input.md をレビューし、前と後の違い 10 か所がすべて指摘に入るかを見る
- 別の入力: 出荷指示の設計書 (章番号の飛び、あいまいな言葉「必要に応じて」「十分」、要求番号なし) をレビューする
- うまくいかなさそうな入力: 中身が空のファイル、見出しのない箇条書きのメモ、ないパス、1,200 行の大きい設計書 (章番号の飛びと重なりを 1 つずつ入れる) を渡し、スクリプトが理由を出して止まるか、大きくても行番号付きで拾えるかを見る
