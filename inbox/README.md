# 材料置き場

スキルにしたい作業の材料を置く。ここに置いたものは Git に入らない (この README だけ入る)。

```
inbox/
  <スキルの名前>/
    memo.md     いつもの進め方 (箇条書きでよい。なくてもよい)
    input/      入力の例 (元のメモ、データ、コード、レビュー前の資料)
    output/     出力の例 (できあがった報告書、仕様書、レビューを受けて直した後の資料)
    trials/     new-skill がスキルを試したときの入力と結果 (new-skill が作る)
```

置いたら、チャットで `/new-skill <スキルの名前> <作業の説明>`。

- 例は 1〜3 組で足りる。2 組以上あると、毎回同じ部分 (型) と毎回変わる部分を見分けやすい。
- レビューの自動化なら、`input/` にレビュー前、`output/` に直した後の同じ資料を、同じファイル名で置く。前と後の違いから、確かめる観点を作る。指摘の一覧の実物があれば `output/` に `<ファイル名>-review.md` で置く (なければ `memo.md` に一覧の列を書く)。
- スキルができたら、材料は消してよい。
